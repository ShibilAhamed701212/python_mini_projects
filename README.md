# Python Mini Projects Collection

A collection of beginner-friendly, professionally formatted Python CLI applications. This repository demonstrates core Python concepts like control flow, input validation, modularization, and PEP 8 best practices.

## 🚀 Projects Included

### 1. 🎲 Dice Rolling Game (`dice_rolling_game.py`)
A simple dice simulator that allows users to roll multiple dice at once and tracks the total number of rolls in a session.

### 2. 🔢 Number Guessing Game (`guessing_numbers.py`)
A classic "higher or lower" guessing game with customizable ranges and smart feedback on how close your guess is.

### 3. 📋 Name List Manager (`name-list-manager.py`)
A utility to manage a list of names. Supports viewing, adding, removing, and clearing the entire list.

### 4. ✂️ Rock Paper Scissors (`rock_paper_scissors.py`)
The timeless game against the computer, featuring input validation and a persistent game loop.

## 🛠️ Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/python_mini_projects.git
   cd python_mini_projects
   ```

2. **Run any project:**
   ```bash
   python name_of_script.py
   ```

## 📐 Professional Standards
Each script in this collection follows:
- **Modular Design:** Logic is encapsulated in functions.
- **Entry Points:** Uses `if __name__ == "__main__":` blocks.
- **PEP 8:** Follows Python's official style guide for naming and structure.
- **Input Validation:** Robust error handling for user inputs.
- **Documentation:** Clear docstrings for every function.
